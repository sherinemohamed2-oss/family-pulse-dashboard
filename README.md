## 📌 Executive Summary

The **Family Pulse Dashboard** aggregates socio-economic data across 1,701 families and 11,905 individuals to assist humanitarian organizations and planners in identifying vulnerable household profiles[cite: 1, 2].

### Core Key Performance Indicators (KPIs)
* **Total Members:** 11,905 beneficiaries[cite: 1, 2]
* **Total Families:** 1,701 households[cite: 1, 2]
* **Total Household Income:** $58,385[cite: 1, 2]

## ⚙️ Dashboard Slicers & Dynamic Filters

* **House Type Slicer:** Filter metrics by accommodation type (`Flat`, `Room`, `Tent`, `House`)[cite: 1, 2].
* **Country Slicer:** Isolate metrics for `Syria`, `Yemen`, `Iraq`, or `Libya`[cite: 1, 2].
* **Breadwinner Slicer:** Filter families by primary income earner profiles[cite: 1, 2].
